# Examples

This directory is reserved for small, focused examples that demonstrate safe ways to connect agent workflows to Base.

## Planned examples

- `read-only/` — query a Base network and inspect public onchain data.
- `transaction-preview/` — validate and display a transaction before user approval.
- `x402-client/` — call an x402-enabled endpoint with explicit payment policy checks.
- `mcp-tools/` — expose a small allowlist of Base tools through MCP.

Each example should include its prerequisites, environment variables, how to run it, expected output, and a note explaining which actions require user approval. Do not add real secrets or mainnet-funded examples.
